## 2. 9 张图性别分配规则

### 2.1 摩登新贵女

```txt
9 张全部使用女性模特
不出现男性主模特
允许背景路人，但不能抢占主体
```

### 2.2 其他三类人群

由于每组默认 9 张图，男女各半需要做近似分配。

默认规则：

```txt
4 张女性模特
4 张男性模特
1 张可为产品远景 / 双人图 / 无明显性别主导的氛围图
```

如果产品更偏女性或男性，可通过 JSON 字段调整。

# 3. 摩登新贵女

## 3.1 人群定位

25–35 岁，高消费力女性。她们不只是为了功能购买旅行产品，而是把旅行看作审美、生活方式、自我表达和灵感发现的一部分。

她们需要的是：

```txt
高级感
审美表达
精致松弛
城市与度假之间的切换
轻奢但不炫耀
```

## 3.2 模特气质

```txt
女性
25–35 岁
自信但不强势
精致但不网红
松弛但不邋遢
有审美判断力
像设计师、创意人、精品买手、品牌主理人
```

## 3.3 穿搭方向

推荐：

1. 米白色、奶油色、浅卡其、黑白极简
2. 垂坠感长裤
3. 质感背心、衬衫、针织、长裙
4. 墨镜、低调首饰
5. 简洁凉鞋、乐福鞋、短靴
6. 度假但不暴露

禁止：

1. 过度性感
2. 低端网红裙
3. 夸张亮片
4. 廉价小香风
5. 浮夸 Logo 服装
6. 过度浓妆

## 3.4 推荐场景

```txt
地中海海岸
精品酒店大堂
艺术街区
设计师民宿
城市露台
机场贵宾区
安静街角咖啡馆
高端度假村
欧洲老城街道
极简建筑空间
```

## 3.5 视觉关键词

```txt
modern feminine luxury
quiet confidence
editorial travel lifestyle
soft natural light
minimal elegant styling
premium resort mood
refined city vacation
```

## 3.6 禁止感觉

```txt
不能性感卖弄
不能网红摆拍
不能廉价街拍
不能太商务
不能像淘宝女装图
不能过度甜美
```

# 4. 轻熟质享客

## 4.1 人群定位

25–45 岁，男女皆有。他们把旅行视为犒赏好生活的投资，追求可靠、舒适、安心和高质感。

他们不是追求炫耀，而是重视产品是否让旅途更轻松、更体面、更有品质。

## 4.2 模特气质

```txt
25–45 岁
男女皆有
成熟但不老气
自然亲和
有生活质感
像中高收入城市白领、设计从业者、精品生活方式消费者
```

## 4.3 穿搭方向

推荐：

1. 简洁衬衫
2. 针织上衣
3. 亚麻外套
4. 休闲西裤
5. 干净 T 恤
6. 低饱和色系
7. 轻熟度假穿搭

禁止：

1. 过度商务西装
2. 低端运动装
3. 太潮太年轻
4. 大面积荧光色
5. 廉价情侣装

## 4.4 推荐场景

```txt

精品民宿
高铁站
机场出发层
周末度假酒店
城市街头
家庭轻度假
海边步道

车站外自然等候场景
```

## 4.5 视觉关键词

```txt
relaxed premium lifestyle

warm natural light
```

## 4.6 禁止感觉

```txt
不能像硬广
```

# 5. 云端商务家

## 5.1 人群定位

35 岁以上，高频商旅人士。旅行是专业形象的延伸，他们重视效率、体面、优雅、可靠和从容。

注意：这里不是传统商务照。画面不能变成办公室、西装广告或严肃企业宣传片。

## 5.2 模特气质

```txt
35 岁以上
男女皆有
专业但松弛
成熟有判断力
优雅克制
像高频出差的管理者、创业者、咨询顾问、建筑师、国际业务人士
```

## 5.3 穿搭方向

推荐：

1. 高级通勤外套
2. 质感衬衫
3. 深色针织
4. 轻商务休闲裤
5. 极简大衣
6. 干净皮鞋或乐福鞋
7. 中性色系

禁止：

1. 传统黑西装白衬衫保险销售感
2. 领带过于正式
3. 办公室工牌感
4. 严肃会议室感
5. 廉价商务摄影棚感

## 5.4 推荐场景

```txt
机场出发大厅
机场贵宾休息区
高端酒店大堂
城市商务街区
商务舱候机区
出租车 / 专车上下车瞬间
会议结束后的城市街道
酒店走廊
国际航站楼
```

## 5.5 视觉关键词

```txt
elegant business travel

calm professional presence
refined mobility
quiet authority
modern executive travel
```

## 5.6 禁止感觉

```txt
不能太商务
```

# 6. 潮奢原生代

## 6.1 人群定位

18–24 岁，高潜力年轻群体。他们把旅行看作大型社交游戏，追求活力探索、社群认同、个性表达和分享欲。

画面要年轻，但不能廉价；要潮流，但不能土潮；要社交化，但不能低端网红。

## 6.2 模特气质

```txt
18–24 岁
男女皆有
年轻、有活力、有探索感
自然松弛
像创意学生、年轻摄影师、音乐节玩家、城市探索者、潮流生活方式消费者
```

8. 城市户外感

禁止：

1. 土味潮牌
2. 大面积廉价印花
3. 过度性感
4. 夜店风
5. 低端网红风
6. 非主流夸张造型

## 6.4 推荐场景

## 6.5 视觉关键词

## 6.6 禁止感觉

# 7. 人群选择逻辑

Agent 根据输入中的 `audience` 字段选择对应规则。

示例：

```json
{
  "audience": "modern_new_elite_woman"
}
```

如果未指定人群，Agent 应停止生成并返回：

```txt
缺少 audience 字段，请指定以下之一：
modern_new_elite_woman / relaxed_quality_customer / cloud_business_traveler / luxury_native_gen_z
```

---

# 8. 人群与主题自动变化规则

每次生成时，Agent 必须根据：

```txt
人群 + 主题 + 产品
```

自动改变：

1. 模特年龄
2. 模特性别
3. 穿搭
4. 场景
5. 光线
6. 构图
7. 使用动作
8. 情绪表达
9. 风格比例

不能所有人群共用同一套画面。
